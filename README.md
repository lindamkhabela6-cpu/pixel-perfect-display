AI Workplace Productivity Assistant

A modern, responsive, frontend-only SaaS web application designed to help professionals organise workplace tasks and improve productivity with AI-powered workflows.

Overview

AI Workplace Productivity Assistant provides a simple workspace for:

✉️ Generating professional emails

📅 Planning and prioritising tasks

🔎 Summarising research topics and articles

🎮 Taking a quick break with Tic Tac Toe vs AI

💡 Receiving occasional motivational quotes

The application is designed to be friendly, lightweight, responsive, and easy to navigate.

Getting Started

1. Clone the repository

git clone https:https://work-with-ai-assistance.lovable.app

2. Navigate to the project

cd ai-workplace-productivity-assistant

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local development URL shown in your terminal.
